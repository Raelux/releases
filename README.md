# Raelux releases

Installers and update files for **Raelux**, a free RAW photo editor for Windows 11, published by Jobic Martin.

- Download the installer from the [Releases](https://github.com/Raelux/releases/releases) page.
- Each release also holds the source code of `raelux_rawdecode.dll` (LGPL-2.1), as explained in Raelux under Settings › About › Third-party licenses.

The installer is not code-signed yet: Windows SmartScreen asks you to confirm its first launch (More info › Run anyway).
